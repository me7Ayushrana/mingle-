# Mingle — Authentic Expression, Zero Judgment

> A modern, anonymous real-time social connection platform built with React Native (Expo) and Node.js Express.

![Mingle Banner](https://images.unsplash.com/photo-1517841905240-472988babdf9?w=1200&auto=format&fit=crop&q=80)

## ✨ Features

- **🎭 100% Anonymous First**: Express yourself freely with auto-generated aliases and vibrant avatar presets.
- **⚡ Radar Vibe Matching**: Match in real-time based on your current vibe (*Chill, Deep Chat, Excited, Creative, Venting, Romantic, Chaotic, Mindful*).
- **⏳ 24h Ephemeral Chats**: Low-pressure conversations that automatically expire unless both parties mutually agree to extend.
- **🎭 Mask Drop**: Reveal real identities only when both users feel genuine chemistry and mutual comfort.
- **🎵 Ambient Soundscapes**: Shared audio co-presence with soothing rain, cafe, and fireplace backgrounds.
- **🌐 Community Moments**: Share unfiltered thoughts with spring-reaction likes, comments, and fast sharing.
- **🏰 Vibe Tribes**: Public and invite-only community groups with dedicated tribe chats.

---

## 🛠️ Tech Stack

- **Frontend**: React Native, Expo Router, Reanimated 3, Gesture Handler, Expo Blur & Linear Gradient.
- **Backend**: Node.js, Express, Socket.IO, Mongoose, JWT Authentication.
- **Database**: MongoDB Atlas.
- **Deployment**: Vercel (Frontend SPA) + Render (Backend Web Service).

---

## 🚀 Quick Start

### 1. Clone & Install
```bash
# Install Server Dependencies
cd server
npm install

# Install Client Dependencies
cd ../client
npm install
```

### 2. Run Locally
```bash
# Start Backend
cd server
npm run dev

# Start Frontend
cd client
npx expo start --web
```
